# Site UNICID

Simulado estático em HTML publicado via GitHub Pages.

## Estrutura

- `index.html`: marcação principal do simulado
- `styles.css`: estilos responsivos
- `questions.js`: banco de perguntas
- `app.js`: lógica do quiz
- `assets/questions/`: imagens usadas nas questões

## Publicação

O site é servido diretamente da branch `main` pelo GitHub Pages.
